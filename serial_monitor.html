Fields are auto-detected from label: value, label -> value, label=value pairs and single-line JSON objects — no per-project config needed. Known gaps: a trailing third value in key:value:meta triplets (e.g. server_v2a's age-ms suffix) is dropped, and readings split across multiple print lines are recorded as separate samples rather than merged into one row.

Recordings autosave to this browser's storage every few seconds, so closing the tab doesn't lose them — reopen them from the Library tab. Only one program can hold the serial port at a time — close Arduino IDE's Serial Monitor/Plotter before connecting here.
